# Scheduling - Genetic Algorithm

For Artificial Intelligence Programming we were tasked with creating two GAs, the first "hello world" one that maximizes a string a 0's and 1's, and then this one. Hence this one is referred to as "GA2" through the documents.

In this project I have developed (from scratch) a genetic algorithm to optimize a university course schedule.

**GA2_Analysis_shultz.pdf** documents the entire project including a detailed breakdown of the problem and the design of the GA as well as analyzing results.

The **analysis** directory contains CSVs, graphs, and terminal output from the program. Yes, I know elite is spelled wrong.
